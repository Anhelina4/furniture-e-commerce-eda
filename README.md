# Project Overview: furniture-e-commerce-eda

This notebook presents a comprehensive exploratory analysis of an online store's sales data extracted from Google BigQuery. The analysis covers 349,545 sessions over the period 2020-11-01 to 2021-01-31 (92 days, holiday-heavy).

Data Source: Google BigQuery — DA dataset Tables used: session, session_params, order, product, account, account_session
